# Module 00 — Resources

The best links for setting up your toolkit, with one line on why each is worth your time. Most come from the curated lists credited in the repo's `SOURCES.md` (especially dipakkr/awesome-ai-engineering, MIT licence); the rest are official documentation. Product details change often: as of late 2026, always check the official page.

## Install and core tools (official)

| Resource | Why use it |
|---|---|
| [Python downloads](https://www.python.org/downloads/) | The one trustworthy place to get a Python installer for any operating system. |
| [Python 3 documentation](https://docs.python.org/3/) | The reference for the language; its "Installing" and `venv` pages back up section 9 of the lesson. |
| [Visual Studio Code docs](https://code.visualstudio.com/docs) | Official guides for the editor, the Python extension, notebooks, the terminal and the Git panel. |
| [Project Jupyter](https://jupyter.org) | Explains JupyterLab, the classic notebook and kernels from the people who make them. |
| [Google Colab](https://colab.research.google.com) | Free browser notebooks with a GPU; open the welcome notebook for an official tour. |
| [uv (Python package and project manager)](https://docs.astral.sh/uv/) | A fast all-in-one replacement for `venv` + `pip` once the classic tools feel comfortable. |

## Git and GitHub

| Resource | Why use it |
|---|---|
| [Pro Git book](https://git-scm.com/book/en/v2) | Free, official and thorough; chapters 1–3 cover everything in this module. |
| [git — the simple guide](http://rogerdudler.github.io/git-guide/) | A one-page overview of the dozen commands beginners actually use. |
| [Atlassian Git tutorials: comparing workflows](https://www.atlassian.com/git/tutorials/comparing-workflows) | Clear diagrams of branch and pull-request workflows used by teams. |
| [Intro to Git and GitHub (video playlist)](https://www.youtube.com/playlist?list=PLRqwX-V7Uu6ZF9C0YMKuns9sLDzK6zoiV) | A friendly video walk-through for learners who prefer watching to reading. |
| [GitHub Student Developer Pack](https://education.github.com/pack) | Free tools and credits for verified students; worth applying for on day one. |

## Practice environments and helpers

| Resource | Why use it |
|---|---|
| [Kaggle Learn](https://www.kaggle.com/learn/overview) | Another free hosted-notebook option with short micro-courses, useful when Colab GPUs are busy. |
| [Python Tutor](https://pythontutor.com/visualize.html#mode=edit) | Draws what each line of code does, which helps when testing your first scripts. |

## Looking ahead (install later, read now)

| Resource | Why use it |
|---|---|
| [Docker overview](https://docs.docker.com/get-started/overview/) | A short conceptual intro to containers, which return in module 14. |
| [Docker documentation](https://docs.docker.com/) | Full install guides per operating system for when you reach deployment. |
