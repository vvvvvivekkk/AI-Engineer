# Exchanges

If an item does not fit or you picked the wrong colour, you can exchange it instead of returning it.

## Size and colour exchanges

Exchanges for a different size or colour of the same product are free and can be requested within **30 days of delivery** (60 days for Gold members). Start the exchange from the **Orders** page and choose **Exchange** instead of **Return**.

## Stock availability

We reserve the replacement item for you for 7 days while your original item travels back to us. If the replacement is out of stock, we refund you instead.

## Exchanging for a different product

Exchanges are only for the same product. If you want a different product, return the original item for a refund and place a new order.

## In-store exchanges

You can exchange online orders in any Brightleaf store. Bring the item and your order number. Store staff can check stock in all stores and ship the replacement to your home for free.
