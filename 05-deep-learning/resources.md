# Module 05 — Resources

Hand-picked links with one line each on why they help. Most come from the course's source catalogues (licences in the root `SOURCES.md`); a few are official PyTorch / Colab pages. Descriptions are our own. Course formats and prices change — as of late 2026, check each page.

## Start here (official)

| Resource | Why |
|---|---|
| [PyTorch tutorials](https://pytorch.org/tutorials/) | The official path from tensors to autograd to the training loop — the same order as our notebooks. |
| [PyTorch — Learn the Basics](https://pytorch.org/tutorials/beginner/basics/intro.html) | A short, end-to-end beginner series (data, model, autograd, optimisation, saving) to set as homework after notebook 02. |
| [PyTorch — Saving and loading models](https://pytorch.org/tutorials/beginner/saving_loading_models.html) | Official guidance on `state_dict`, checkpoints and loading across devices (section 11 of `concepts.md`). |
| [PyTorch home, install selector and API docs](https://pytorch.org/) | Look up any `torch.nn` layer, loss or optimizer; the "Get Started" page gives the right install command for your machine. |
| [Google Colab FAQ](https://research.google.com/colaboratory/faq.html) | Current, official information on Colab runtimes and GPU usage limits, which change often. |

## Courses and books (free or free to audit unless marked)

| Resource | Level | Why |
|---|---|---|
| [Practical Deep Learning for Coders (fast.ai)](https://course.fast.ai/) | Beginner | Top-down: build working models first, then learn how they work. Very motivating for new learners. |
| [Neural Networks: Zero to Hero (Andrej Karpathy)](https://www.youtube.com/watch?v=VMj-3S1tku0&list=PLAqhIrjkxbuWI23v9cThsA9GvCAUhRvKZ) | Intermediate | Builds backprop and MLPs by hand, then a small GPT — the best way to remove the "magic" from autograd. |
| [Neural Networks and Deep Learning (Michael Nielsen)](http://neuralnetworksanddeeplearning.com/) | Beginner | Gentle free online book on how and why networks learn; excellent for trainers' own understanding. |
| [Dive into Deep Learning (D2L)](https://d2l.ai/) | Intermediate | Free interactive textbook with runnable PyTorch code for every chapter, including CNNs. |
| [Deep Learning Specialization (Coursera)](https://www.coursera.org/specializations/deep-learning) | Intermediate | Systematic theory: initialisation, regularisation, CNNs, sequence models. |
| [Deep Neural Networks with PyTorch (Coursera, IBM)](https://www.coursera.org/learn/deep-neural-networks-with-pytorch) | Intermediate | PyTorch-first course with graded exercises. |
| [Deep Learning with Python, 2nd ed. (François Chollet)](https://www.manning.com/books/deep-learning-with-python-second-edition) | Intermediate | Paid book; Keras-based but outstanding for practical intuition. |
| [NVIDIA Deep Learning Institute](https://developer.nvidia.com/dli) | Intermediate | GPU-focused hands-on labs (some free, some paid). |

## Other frameworks worth recognising

| Resource | Why |
|---|---|
| [Keras](https://keras.io/) | High-level API; many online tutorials use it, so students should be able to read it. |
| [TensorFlow](https://tensorflow.org) | Still common in industry and mobile deployment. |

## Practice data and projects

| Resource | Why |
|---|---|
| [Fashion-MNIST](https://github.com/zalandoresearch/fashion-mnist) | The natural next dataset after 8×8 digits: 28×28 clothing images, a real CNN challenge (needs a download, so it is not used in our offline notebooks). |
