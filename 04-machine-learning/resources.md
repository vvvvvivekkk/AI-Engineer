# Module 04 — Resources

Hand-picked links, grouped by purpose, each with one line on why it is worth your time. Most come from the course's source catalogues (see the root `SOURCES.md` for licences); a few are official scikit-learn pages. All descriptions are our own. Prices and course formats change — as of late 2026, check each page.

## Start here (official documentation)

| Resource | Why |
|---|---|
| [scikit-learn documentation](https://scikit-learn.org/stable/) | The library used in every notebook here; its User Guide explains each algorithm with small runnable examples. |
| [scikit-learn — Metrics and scoring](https://scikit-learn.org/stable/modules/model_evaluation.html) | The official reference for accuracy, precision, recall, F1, ROC-AUC, MAE, RMSE and R² — useful when a student asks "which scorer name do I pass?". |
| [scikit-learn — Cross-validation](https://scikit-learn.org/stable/modules/cross_validation.html) | Clear diagrams of k-fold and stratified splits; matches section 12 of `concepts.md`. |
| [scikit-learn — Common pitfalls](https://scikit-learn.org/stable/common_pitfalls.html) | Official write-up of data leakage and inconsistent preprocessing — the mistakes trainer-notes warns about. |
| [scikit-learn — Model persistence](https://scikit-learn.org/stable/model_persistence.html) | How to save models (joblib and alternatives) and the security and version caveats. |

## Courses for learners (free or free to audit)

| Resource | Level | Why |
|---|---|---|
| [Google Machine Learning Crash Course](https://developers.google.com/machine-learning/crash-course/ml-intro) | Beginner | Short, visual lessons on loss, generalisation and classification metrics; great second explanation of this module. |
| [Kaggle Learn — Intro to Machine Learning](https://www.kaggle.com/learn/machine-learning) | Beginner | A few hours of hands-on decision trees and random forests in the browser. |
| [Machine Learning (Andrew Ng, Coursera)](https://www.coursera.org/learn/machine-learning) | Beginner | The classic first course; builds intuition for regression, classification and overfitting. |
| [Machine Learning Recipes (Josh Gordon, YouTube)](https://www.youtube.com/playlist?list=PLOU2XLYxmsIIuiBfYad6rFYQU_jL2ryal) | Beginner | Very short videos that use scikit-learn — ideal to assign as pre-class viewing. |
| [Intro to Machine Learning (Udacity)](https://www.udacity.com/course/intro-to-machine-learning--ud120) | Beginner | Project-based tour of more algorithms (naive Bayes, SVMs) than we cover. |
| [Machine Learning with Python (sentdex, YouTube)](https://www.youtube.com/playlist?list=PLQVvvaa0QuDfKTOs3Keq_kaG2P55YRn5v) | Intermediate | Codes algorithms from scratch next to the library versions — good for curious students. |
| [Stanford CS229](http://cs229.stanford.edu/) | Advanced | The mathematical version, for trainers who want to understand the derivations. |
