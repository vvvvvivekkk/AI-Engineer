# Module 01 — Resources

The best places to keep learning and practising Python, with one line on why each is worth your time. Most come from the curated lists credited in the repo's `SOURCES.md` (mainly dipakkr/awesome-ai-engineering, MIT licence, and ashishpatel26's project list, link only). Course and platform details change, so check each site's current terms.

## Start here

| Resource | Why use it |
|---|---|
| [The Python Tutorial (official)](https://docs.python.org/3/tutorial/) | The language's own walkthrough: accurate, current, and the best reference for anything in this module. |
| [Python Tutor](https://pythontutor.com/visualize.html#mode=edit) | Draws what each line does to variables and lists, which makes loops and the copy trap click. |
| [Automate the Boring Stuff with Python](https://automatetheboringstuff.com/) | Free online book that teaches Python through useful scripts (files, spreadsheets, web), a natural bridge to later automation work. |

## Courses (pick one, finish it)

| Resource | Why use it |
|---|---|
| [Python for Everybody (Coursera)](https://www.coursera.org/specializations/python) | Gentle, well-paced, written for people with no programming background; free to audit. |
| [Google's Python Class](https://developers.google.com/edu/python/) | Short and dense with exercises; good for learners who already know another language. |
| [CS50x (Harvard, edX)](https://www.edx.org/course/cs50s-introduction-computer-science-harvardx-cs50x) | Broader computer-science foundations (memory, algorithms) that make debugging easier later. |
| [freeCodeCamp](https://www.freecodecamp.org/) | Free interactive curriculum with graded Python and scientific-computing projects. |
| [Khan Academy Computing](https://www.khanacademy.org/computing) | The gentlest possible introduction to programming ideas for absolute beginners. |

## Free books

| Resource | Why use it |
|---|---|
| [Think Python 2e (PDF)](http://greenteapress.com/thinkpython2/thinkpython2.pdf) | Explains *why* things work, not only how; good companion for trainers. |
| [A Byte of Python](https://python.swaroopch.com/) | A compact book for a fast first pass over the whole language. |
| [A Whirlwind Tour of Python](https://github.com/jakevdp/WhirlwindTourOfPython) | Notebook-based crash course that leads straight into NumPy and pandas in module 02. |

## Deeper reading when you get stuck

| Resource | Why use it |
|---|---|
| [Real Python](https://realpython.com/) | Well-edited articles on specific topics (exceptions, f-strings, classes) when you need more depth. |
| [Learning Python: From Zero to Hero](https://medium.freecodecamp.org/learning-python-from-zero-to-hero-120ea540b567) | A single-article overview to skim before or after the module. |

## Practice and next steps

| Resource | Why use it |
|---|---|
| [Project Euler](https://projecteuler.net/) | Maths-flavoured puzzles that build loop, function and efficiency skills. |
| [30 Python projects solved and explained](https://amankharwal.medium.com/30-python-projects-solved-and-explained-563fd7473003) | Small project ideas once the syntax feels familiar (Medium may limit free reads). |
| [TheAlgorithms/Python](https://github.com/TheAlgorithms/Python) | Readable implementations of classic algorithms to study and compare with your own. |
| [awesome-python](https://github.com/vinta/awesome-python) | A curated map of Python libraries for finding the right package for a task. |
